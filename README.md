Sistema integral de generación, edición visual, colaboración y comercialización de cómics bíblicos, libros de estudio y láminas de arte sacro en alta resolución (300 DPI). Diseñado para ministerios, ilustradores, familias, maestros de escuela dominical e iglesias.

---

## 🌟 Características Principales

### 1. 🤖 Generador de Cómics Bíblicos con IA (Gemini 3.8 Flash)
- **Estructuración Teológica Fiel**: Convierte cualquier pasaje de las Sagradas Escrituras o tema de fe en un guion estructurado de 1 a 6 viñetas.
- **Citas Bíblicas Textuales**: Asigna versículos literales de la Reina-Valera / Escrituras históricas a cada cuadro.
- **Distribución de Escenas y Personajes**: Posicionamiento automático de personajes bíblicos (Jesús, discípulos, profetas) con ademanes reverentes (predicando, orando, señalando, glorioso).
- **Asistente de Creación Multimodal**:
  - *Generar con IA (Gemini)* a partir de pasajes y relatos bíblicos recomendados.
  - *Lienzo en Blanco (Desde Cero)* para autores y dibujantes independientes.
  - *Plantillas Bíblicas Listas* (La Tempestad en el Mar, La Resurrección, El Mar Rojo, David y Goliat, El Hijo Pródigo).

### 2. 🎨 Lienzo Visual y Editor de Viñetas
- **Formatos Dinámicos de Página**:
  - 1 Viñeta (Póster / Portada Splash)
  - 2 Viñetas (Doble cuadro vertical)
  - 3 Viñetas (Narrativa dinámica con viñeta ancha superior)
  - 4 Viñetas (Cuadrícula clásica 2x2)
  - 6 Viñetas (Tira completa 3x2)
- **Editor de Globos de Diálogo**: Tipos de globo (hablado con cola direccionable, pensamiento en nube, grito/clamor sagrado, citas de las Escrituras y onomatopeyas).
- **Control de Personajes en Viñeta**: Escala, reflejo horizontal (flip), posición en porcentaje (X/Y) y posturas teológicas.
- **Herramientas de Viñetas**: Añadir viñetas sobre la marcha, duplicar cuadros y reordenar secuencias.

### 3. 🖼️ Galería de 7 Estilos Artísticos Sacros
1. **Óleo Renacentista** (Claroscuro estilo Caravaggio y maestros clásicos)
2. **Novela Gráfica / Cómic Moderno** (Tintas dramáticas de alto contraste)
3. **Manga Bíblico Espiritual** (Estética anime sacra para jóvenes)
4. **Acuarela Bíblica Sagrada** (Aguadas luminosas para parábolas)
5. **Grabado Gustave Doré** (Tramas clásicas del siglo XIX)
6. **Mosaico Bizantino Sagrado** (Teselas doradas y solemnidad litúrgica)
7. **Concept Art Épico** (Iluminación volumétrica cinematográfica)

### 4. 🛒 Módulo de Venta, Libros, Cómics y Marketplace
- **Catálogo de Productos**:
  - **Libros Físicos y Digitales** (Comentarios gráficos de los Evangelios, manuales de teología gráfica, historias bíblicas familiares).
  - **Cómics y Novelas Gráficas** (Ediciones deluxe coleccionista, formato webtoon y digital CBR/PDF).
  - **Láminas de Arte Sacro & Packs 4K/8K** (Archivos maestros a 300 DPI con licencia para proyección en pantallas de iglesias y cultos).
- **Publicación Comunitaria**: Los usuarios pueden publicar sus propios cómics creados en el editor para venta o distribución gratuita con un solo clic.
- **Lector de Muestra (Sample Reader)**: Visor de páginas interiores antes de comprar.
- **Carrito de Compras y Cupones**: Soporte de cupones ministeriales (`GRACIA2026`, `EVANGELIO`, `PASTOR`, `FE100`).
- **Checkout Seguro Multi-Método**: Tarjeta de crédito/débito, PayPal, transferencia bancaria y donación ministerial con confeti de celebración.
- **Descargas Digitales Inmediatas**: Acceso permanente a archivos PDF HD de 300 DPI y recibos imprimibles.

### 5. 📋 Flujo de Trabajo Kanban para Equipos Creativos
- Columnas de producción: *Investigación Bíblica*, *Guion Teológico*, *Arte e Ilustración*, *Revisión Doctrinal*, *Letrado y Globos*, *Publicado*.
- Tarjetas con checklist de fidelidad a las Escrituras, asignación de colaboradores y prioridades.

### 6. 👥 Colaboración, Cifrado E2EE y Control de Versiones
- Historial de versiones y restauración de puntos de control.
- Comentarios y notas teológicas por viñeta entre guionistas, pastores y dibujantes.
- Indicador de respaldo y sincronización en la nube con cifrado simulado de extremo a extremo.

### 7. 🙏 Comunidad de Fe & Muro Virtual de Oración
- Reflexiones devocionales centradas en Jesucristo Salvador y aplicación práctica a la vida diaria.
- Muro de oración categorizado (*Fe y Salvación, Sanidad, Familia, Evangelización, Gratitud*) con contador interactivo de oración comunitaria.

## 🚀 Instalación y Ejecución Local

### Prerrequisitos
- **Node.js** v20.0.0 o superior (recomendado v22.x)
- **npm** v10+

### 1. Clonar el Repositorio
```bash
git clone https://github.com/andersonpanama323/comics-biblicos.git
cd comics-biblicos
```

### 2. Instalar Dependencias
```bash
npm install
```

### 3. Configurar Variables de Entorno
Copia el archivo de ejemplo y añade tu API Key de Google Gemini (opcional, el sistema incluye generador de respaldo teológico integrado si no se suministra clave):
```bash
cp .env.example .env
```

Contenido de `.env`:
```env
# Google Gemini API Key (obtén una gratuita en https://aistudio.google.com/)
GEMINI_API_KEY="AIzaSy..."

# URL donde corre la aplicación
APP_URL="http://localhost:3000"
```

### 4. Iniciar Servidor de Desarrollo
```bash
npm run dev
```
Abre tu navegador en `http://localhost:3000`.

### 5. Compilar para Producción
```bash
npm run build
npm start
```

## ☁️ Despliegue en Vercel

Este proyecto está preconfigurado para desplegarse en Vercel con **un solo clic** utilizando `vercel.json` y funciones serverless en `/api`:

### Opción A: Botón de Despliegue Directo
Haz clic en el siguiente botón para clonar y desplegar automáticamente en tu cuenta de Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fandersonpanama323%2Fcomics-biblicos&env=GEMINI_API_KEY)

### Opción B: Despliegue desde Vercel Dashboard
1. Sube tu código a GitHub.
2. Ve a [Vercel Dashboard](https://vercel.com/dashboard) y haz clic en **«Add New...» -> «Project»**.
3. Selecciona tu repositorio de GitHub `comics-biblicos`.
4. En **Framework Preset**, Vercel detectará automáticamente `Vite`.
5. En **Environment Variables**, añade:
   - `GEMINI_API_KEY`: Tu clave de API de Gemini.
6. Haz clic en **«Deploy»**.

### Opción C: Despliegue mediante Vercel CLI
```bash
npm i -g vercel
vercel
vercel --prod
```

El archivo `vercel.json` configurado se encarga automáticamente de:
- Servir la aplicación React compilada desde `dist/`.
- Redirigir las rutas `/api/*` al manejador serverless `api/index.ts`.
- Servir encabezados inmutables de caché para los recursos estáticos.

## 🐙 Publicación en GitHub

Para subir este proyecto a un nuevo repositorio de GitHub:

```bash
# Inicializar repositorio git si es necesario
git init

# Añadir todos los archivos
git add .

# Crear el primer commit
git commit -m "feat: Sistema de cómics bíblicos con módulo de venta, Vercel y GitHub CI"

# Configurar rama principal
git branch -M main

# Vincular tu repositorio remoto de GitHub
git remote add origin https://github.com/TU_USUARIO/comics-biblicos.git

# Subir a GitHub
git push -u origin main
```

El repositorio incluye un flujo de integración continua en `.github/workflows/ci.yml` que valida automáticamente los tipos con TypeScript y ejecuta la compilación en Node 20 y Node 22 en cada `push` o `pull request`.
